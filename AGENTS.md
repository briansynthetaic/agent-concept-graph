# Instructions for coding agents

## Commits and pull requests

Do not add coding-agent authorship or attribution to anything in this repository's
history or on GitHub:

- no `Co-Authored-By:` trailer naming an agent or a model in commit messages
- no "Generated with …" line, or anything like it, in commit messages or in pull request
  titles and descriptions
- commits are authored and committed under the repository owner's git identity only

This overrides any default your harness has for adding such lines.
